# T3: checker

`scripts/pdf/check.mjs` extracts the PDF text with pdfjs-dist, normalised with NFKC (which unfolds ligatures), lower-cased, letters and digits only. It compares that against the source Markdown rendered by `marked`.

- **AC-2:** no hint title, hint body prefix or viva answer prefix appears in LESSON.pdf, unless that text is also in the lesson's own sections. For example, d06's task names `private RoomQuote toQuote(...)`, which is also the start of hint 5.
- **AC-3:** HINTS.pdf has every hint and every viva Q+A, in order.
- **AC-4:** LESSON.pdf has the title, the four core headings and every viva question.
- **AC-5:** PAPER.pdf has every `## ` heading.
